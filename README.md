## Vérification d'intégrité (SHA256)

Chaque release publie le hash SHA256 du binaire. Vérifier avant exécution sous PowerShell :

    Get-FileHash -Algorithm SHA256 .\VisionRGPD.exe

    Le hash retourné doit correspondre exactement à celui annoncé dans les notes de la release.
